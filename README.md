# Element 22

Premium luxury automotive platform for Element 22, Kerala.

## Stack

* Next.js 16
* React 19
* Tailwind CSS v4
* Framer Motion
* TypeScript

## Project Status

Currently evolving from:

* high-fidelity luxury marketing prototype
  into:
* production-grade automotive platform.
